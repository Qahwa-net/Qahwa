**Words used**

- **DocType**: a kind of document (Customer, Order). **Document**: one of them (Customer "Acme").
- **Field**: one piece of information on a document. **Table**: a list of rows inside a document (the lines of an order).
- **Role**: a label given to users (Sales Manager); permissions are given to roles.
- **Module**: a group of DocTypes in the sidebar (Selling).

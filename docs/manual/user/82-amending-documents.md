# Amending a cancelled document

A cancelled document cannot be changed, but you can **amend** it: open it and choose **Amend**. Qahwa makes a new draft with the same values and rows, linked back to the cancelled one in **Amended From**. Correct what was wrong, then submit the new document. A cancelled document can be amended once.

Administrators can take the **Amend** right away from a role in the DocType's permissions.

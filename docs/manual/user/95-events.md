# Events: your calendar

Open **Event** (in the **Calendar** module) to keep dated entries: an appointment, a deadline, a trip. Events open in the **calendar view** by default, a month grid where you click a day to add one.

## Add an event
Give it a **subject**, when it **starts** and (optionally) when it **ends**, tick **All day** if it has no time, and add a place and a description if you want. An event cannot end before it starts. Set its **status** to Completed or Cancelled when it is over; the colour on the calendar follows it (blue, green, grey).

## Who sees it
Only you (and System Managers). Use **Share** on an event to let someone read or change it.

## Be told about it
Click the **bell** (Remind me) on an event to get a notification before it happens, see [Reminders](94-reminders.md). Events do not email or remind anyone on their own.

## Good to know
- An event does not repeat by itself. To repeat one, use **Repeat** (see [Auto Repeat](11-auto-repeat.md)), which makes a new draft on a schedule and sets its dates.
- Other DocTypes with date fields have a calendar button on their list too; Event is just the one made for your own entries.

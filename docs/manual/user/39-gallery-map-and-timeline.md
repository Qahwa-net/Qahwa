# Gallery, map and timeline

Besides the list, board and calendar, a DocType can be shown three more ways. The buttons appear in the list toolbar when the DocType has the fields they need.

- **Gallery** (needs an **Image** field): pictures as tiles; click one to open the document.
- **Map** (needs a **Geolocation** field): the places as dots; click a dot to open the document. The grid shows latitude and longitude. For a real map, use **View on a map** next to each place. The map view deliberately does not load a map from the internet, so nobody outside learns what you look at.
- **Timeline** (needs two date fields, such as Start and End): each document is a bar from its start to its end, with a dashed line for today. Choose which dates to use at the top. Documents with a missing date, or an end before the start, are listed as not shown.

Each view shows the 500 most recently changed documents.

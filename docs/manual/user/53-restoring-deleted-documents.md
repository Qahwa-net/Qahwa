# Restoring deleted documents

When someone deletes a document by mistake, a System Manager can bring it back.

1. Open **Deleted Document** (search for it, or use the list of DocTypes). Each row says what kind of document it was and its name; filter by DocType to narrow it down.
2. Open the row and press **Restore**. The document comes back with the same name, values and table rows, and you are taken to it.

Things to know:
- Copies are kept for **30 days** (your administrator can change that), then removed. You can also delete a copy yourself if it should not be kept.
- If a new document with the same name exists, restoring is refused. Rename or delete the new one first, then restore.
- Comments, attached files, shares and assignments of the deleted document are **not** brought back. Password fields are never kept.
- Very large documents (over about 1 MB of data) are deleted without a copy.
- Only people with the System Manager role who may also create that kind of document can restore it. The document's history shows a "Restore" entry.

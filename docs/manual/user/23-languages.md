# Languages and right-to-left

Pick your language in the top bar. The sidebar, DocType names, module names and field labels appear in that language, and for right-to-left languages (Arabic, Hebrew, Persian, Urdu) the whole screen is mirrored. The choice is remembered in your browser. Where there is no translation, the English text is shown.

## Adding or fixing translations (System Manager)
1. Open **Translation** in the sidebar and choose **New**.
2. **Language code**: for example `ar`, `fr`, `pt-BR`.
3. **Source text**: the English text exactly as it appears (a field label such as `Customer name`, or a DocType or module name).
4. **Translation**: the text to show instead.

The language then appears in the language list for everyone. If a text is translated twice, the newest one is used. Translations are shown as plain text, so markup in them is never run.

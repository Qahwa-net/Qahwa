# Slow requests (for System Managers)

Open **Tools → Slow Requests** to see the slowest requests this server has answered since it started, when they took at least one second. Each line shows the address, how long it took, how many statements it sent to the database and how long those took, who asked and when. Hundreds of statements for one page usually means the page asks for one row at a time. Nothing typed into a request is kept. Each server keeps its own list, and a restart clears it. To see the database queries behind a slow request, use your database's own tools. Administrators can change the limit with `Qahwa:Recorder:SlowMs` (0 turns this off).

# User types

Every user is either a **System User** (staff) or a **Website User** (a customer or visitor).

- Open the user and choose **User Type**.
- A **Website User** gets only the *Website User* role, even if other roles are listed. This protects the system if a role is added by mistake. Change the type back to *System User* and the listed roles apply again immediately.
- Give portal DocTypes permissions to the **Website User** role when customers should see them.

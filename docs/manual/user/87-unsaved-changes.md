# Unsaved changes are kept

If you close the tab, lose the connection or reload while a form has changes you have not saved, Qahwa keeps a copy in your browser. Open the same document (or the same new form) again and your typing comes back with a note: **Your unsaved changes were restored**. Press **Discard them** to start from the saved version.

Passwords are never kept. The copy stays only in your browser and is dropped after a week, once you save, or when someone else has saved the document in the meantime. On a shared computer use your own browser profile.

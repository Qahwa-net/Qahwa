# Web pages

A **web page** is a page anyone can read without signing in: an about page, opening hours, news. Open **Tools → Web Page** (System Managers) and add one:

- **Address**: lower-case letters, digits and dashes, for example `about-us`. The page is then at `/pages/about-us`.
- **Title**, and **Content** (the editor keeps text, headings, lists, tables and links; scripts, styles and other risky things are removed).
- **Summary** and **Date shown**: used in the index. Pages in the index are newest first; with no date, the day it was first published is used.
- **Published**: until you tick it, nobody but you can see the page; a draft looks like a page that does not exist.
- **Listed on the pages index**: ticked, the page appears at `/pages`. Untick it to keep the page for people who have the link.

Visitors need no account. Link to `/pages` or to a single page from anywhere. Pages are text and links only; there are no uploads or comments yet.

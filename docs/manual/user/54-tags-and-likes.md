# Tags and likes

## Tags
Tags are short labels you put on a document to find it again ("urgent", "q3 review").

- Open a document: the **Tags** card on the right shows its tags. Type in **Add a tag…** and press Enter. Suggestions are tags other documents of the same kind already use.
- Press **×** on a tag to remove it.
- You need the right to change the document to add or remove tags; anyone who can read it sees them.
- A tag is lower case, up to 40 characters, with no commas. A document can have up to 20.

In a list, the tags in use appear above the group-by counts. Click one to show only documents with that tag; click it again to remove the filter.

## Likes
The heart button next to **Follow** likes a document (click again to take it back). The number is how many people like it. Anyone who can read the document can like it. In a list, **Liked by me** shows the documents you liked.

Tags and likes go away when the document is deleted.

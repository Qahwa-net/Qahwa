# Choosing several documents (multi-select)

A table that holds a single kind of document, for example the **Skills** of a candidate, can be shown as a list of chips:

- Type in the box to search and pick a document; it appears as a chip.
- Click the **×** on a chip to take it away.
- The same document can be chosen only once.

Administrators turn this on in the DocType designer: on a **Table** field tick *Show as a list of chips*. The table's child DocType must have exactly one Link field and no other required field.

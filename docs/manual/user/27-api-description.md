# API description (OpenAPI)

Developers who connect other systems can read what the API offers at **`/api/openapi.json`** (sign in first, or send an API key as `Authorization: Bearer qk_...`). It lists exactly the DocTypes, fields and actions **you** may use, so two people see different descriptions. Open the file in Swagger UI, Postman or any OpenAPI tool.

It is generated from your DocTypes, so a DocType you add today appears at once.

# Stricter sign-in and password rules (System Managers)

In **System Settings** you can ask for a longer minimum password, a shorter longest sign-in and a regular password change. These can only make the rules stricter than the server configuration, never looser: a smaller minimum or a longer sign-in than the configuration allows is ignored. 0 means "as configured". A longer minimum applies to passwords set from then on; a shorter sign-in applies to new sign-ins.

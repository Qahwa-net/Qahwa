# Stars, durations, colours, barcodes, places and signatures

When you design a DocType (**DocType Designer**) these field types are available besides text and numbers:

- **Rating**: 0 to 5 stars. Click a star; click the same star again to clear it.
- **Duration**: a length of time. Type `1h 30m`, `2d`, `1:30` (hours and minutes) or a number of seconds. It shows as `1h 30m`.
- **Color**: pick a colour, or type it like `#1a2b3c`.
- **Barcode**: the text of a barcode or QR code (typed or pasted from a scanner).
- **Geolocation**: latitude and longitude. **Use my location** fills them in from your device (your browser asks first); **View on map** opens the place in OpenStreetMap.
- **Icon**: choose one picture from a set of icons; click the chosen one again to clear it.
- **Signature**: sign in the box with the mouse or a finger, **Clear** to start again. A saved signature shows as a picture; **Sign again** replaces it.

In lists and reports ratings show as stars and durations as `1h 30m`. Averages and totals work on ratings and durations. On printouts a signature shows only as "(signed)".

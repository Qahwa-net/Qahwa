# Choosing DocTypes and documents

Wherever a form asks for a **DocType** (Auto Repeat, Document Action, Web Form, Print Format, Email Template ...) you choose it from a searchable list, not by typing its name. The list shows the DocTypes you are allowed to read, with their module.

Where a form asks for a **Document** next to a DocType, first choose the DocType; then the Document box lets you search that DocType's documents by name or title. If you change the DocType, the document is cleared, because it belonged to the old one.

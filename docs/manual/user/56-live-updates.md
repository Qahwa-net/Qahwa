# Live updates

You do not have to refresh the page to see what others do.

- **Notifications:** the bell shows a new notification as soon as it arrives.
- **Documents:** if you have a document open and someone else saves it, the form shows their version and a message "Updated by …". If you have unsaved changes of your own, your form is **not** changed; instead a message tells you who changed the document, and **Reload latest** loads their version (your unsaved changes are then lost, so save or copy them first).
- If someone deletes the document you are looking at, a message says so.

Your own changes never trigger these messages. If your connection drops, the browser reconnects by itself; the page keeps working without live updates in the meantime. When the system runs on several servers, you see changes made on the server your browser is connected to.

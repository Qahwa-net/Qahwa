# Script reports

Some installed apps come with their own reports (calculations the report builder cannot do). Open **Script reports**, choose one, fill in its filters (if it has any) and press **Run**. The table can be downloaded as CSV.

- You see only reports meant for your roles, and each report shows only what you may see.
- At most 5,000 rows are shown; a note says when rows were left out.
- Running a report is recorded in the Access Log like an export.
- If a report fails, you get a short message and the problem is recorded for the administrator.

# Password fields

A **Password** field keeps a secret on a document, such as the password of a mail account or the key for another system.

- Type the secret in the field; it is hidden as you type.
- Once saved, the form shows `********` instead of the secret. **Nobody can read it back** from the Desk, a list, an export, a report or a printout.
- To keep the secret, leave the field as it is. To change it, type the new one. To remove it, empty the field.
- You need the right to change the document to set or replace the secret.
- The secret is stored encrypted. If your administrator moves the system to new servers they must move the encryption keys too, or saved secrets cannot be used any more.
- The history of a document says that a password changed, never what it was.

A Password field cannot be used in lists, filters, sorting, charts or reports, and cannot be inside a table (rows). Keep the secret on the main document.

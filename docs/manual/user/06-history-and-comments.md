# History and comments

Every saved document has an **Activity** section under its form. It shows two things in one list, newest first.

## Updates (the history)

Qahwa records every change automatically: **who** changed the document, **when**, and **what each field was before and after**, for example *Status: Open → Won*. It also records when a document was created, submitted, cancelled, renamed, merged or deleted, and changes to table rows (a line added, removed or changed).

- You see changes to the fields **you are allowed to see**. If a field is protected (salary, margin), changes to it are not shown to you.
- Passwords are never shown.
- Nobody can edit or remove history, not even an administrator, so it can be trusted.
- A DocType can switch the history off (in the DocType Designer: *Keep an updates log*); it is on by default.
- Click **Load older** to go further back.

## Comments

Use the box at the top of Activity to talk about a document: write, then **Comment** (or Ctrl+Enter).

- Anyone who can **see** the document can comment, even after it is submitted or cancelled. Commenting does not change the document.
- Type `@` and a name to **mention** someone; mentions are highlighted. (Notifications for mentions come later.)
- You can **Edit** or **Delete** your own comments; an edited comment shows *(edited)*. Administrators can delete any comment.
- Comments are plain text, up to 5,000 characters; formatting characters are shown as typed, not interpreted.
- Deleting a document deletes its comments (its history stays).

## System notes

Some actions leave a grey note in the list, for example *Shared with ana@example.com (can edit)* or *Stopped sharing with ...*. They cannot be edited or deleted.

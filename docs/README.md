# Qahwa documentation

Qahwa is a low-code, metadata-driven framework for .NET: describe a DocType (a kind of document) as data, and you get the database table, the REST API, permissions and the Desk UI. Almost everything an application needs is meant to be edited in the Desk, not in code.

## The rule for new features

A feature is not finished until it is documented: update the developer manual and the user guide, add or update the architecture decision record, and update the README feature list and the plan status. See [Extending and conventions](manual/developer/07-extending-and-conventions.md#documentation-is-part-of-done).
